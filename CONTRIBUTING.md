# Contributing

Thanks for your interest in improving this football analytics project.

## Good first contributions

- Improve data documentation and source attribution.
- Add reproducible preprocessing or evaluation code.
- Add baseline models and compare them with the existing classifiers.
- Improve simulation assumptions and document their effects.
- Add tests for reusable functions as the project is refactored.

## Workflow

1. Fork the repository.
2. Create a branch for your change.
3. Keep changes focused and explain the reasoning.
4. Run relevant notebook cells or tests.
5. Open a pull request with a clear summary and any relevant screenshots or metrics.

## Data and licensing

Do not commit datasets, images or other materials unless their licence permits redistribution. Preserve source attribution and document any transformations.
