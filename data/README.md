# Data directory

`raw/` contains the CSV files supplied with the original FIFA World Cup 2022 analysis archive.

| File | Description |
|---|---|
| `matches.csv` | Historical international match results |
| `players_15.csv` … `players_21.csv` | FIFA player attributes for editions 2015–2021 |
| `players_22_new.csv` | FIFA 22 player attributes |
| `country_rating.csv` | Country attack, midfield, defence, and overall ratings by year |

The original write-up attributes player and match data to Kaggle and country ratings to FIFA Index. Exact dataset URLs, versions, and licences were not included in the supplied archive. Verify attribution and redistribution rights before publishing these files in a public repository.

Keep raw source files unchanged. Put cleaned or derived datasets in a separate `processed/` directory if you add them later, and document how they were generated.
